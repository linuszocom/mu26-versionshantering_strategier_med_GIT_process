# 01 — Historik på din dator

> **📖 Hur du använder materialet:** Detta GitHub-repo fungerar som din digitala kursbok. Du behöver inte klona något för att läsa. Klicka på länkarna i webbläsaren.

**Den här mappen täcker:** måndag 12/10. Terminalen, ett lokalt repo, och de första commitsen.

Onsdag och fredag samma vecka har egna mappar.

## 🗣️ Målsvar att kunna utantill inför examinationen

När veckan är klar ska du kunna återge dessa med egna ord:

> **Versionshantering:** “Senaste filen skriver över sig själv. Historiken är förseglade lägen, med en mening om vad som ändrades.”

> **Staging:** “git add väljer vad nästa commit ska innehålla. git commit förseglar det. git status bara läser.”

---

## 📝 Examination

Den individuella examinationen frågar senare vad versionshantering är, och vad staging gör. De två målsvaren ovan är den grunden. Push och GitHub hör till nästa del, inte till den här mappen.
