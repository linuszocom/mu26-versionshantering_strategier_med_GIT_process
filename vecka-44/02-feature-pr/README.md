## 🗣️ Målsvar att kunna utantill

> **Pull:** “checkout -b kopierar main i min låda. Pull hämtar glaset först, så startfilen finns innan jag tar mitt namn.”

> **Frågan:** “Bas är main, compare är feature och mitt namn. Någon annan Approve. Knappen Merge pull request. Branch, push, PR, review, merge.”

## 📝 Examination

Gruppexaminationen vill se ett gemensamt publikt repo, en mergad Pull Request per person, och ett ja från någon annan innan knappen. Den här mappen är den kedjan. Krocken och teorisvaren ligger i [03-konflikt-readme](../03-konflikt-readme/).
