# 02 — Lådan hemma och montern

> **📖 Hur du använder materialet:** Detta GitHub-repo fungerar som din digitala kursbok. Du behöver inte klona något för att läsa. Klicka på länkarna i webbläsaren.

**Den här mappen täcker:** onsdag 14/10. Publikt repo, remote och `git push`.

Måndag och fredag samma vecka har egna mappar.

## 🗣️ Målsvar att kunna utantill inför examinationen

När veckan är klar ska du kunna återge dessa med egna ord:

> **Lokalt mot GitHub:** “Commit förseglar i lådan. git push bär kopian till montern. Utan push syns den inte under Commits.”

> **När det blir rött:** “Jag läser meningen. Tom adress: lägg till origin. Monter med ett papper redan: nytt tomt repo, byt origin, push igen.”

---

## 📝 Examination

Den individuella examinationen tittar på Commits: minst 5 commits under Commits, äldsta med alla tre TODO kvar, och på sidan: ditt namn, Summa: 12, ok. De tre teorisvaren i README hör till nästa mapp. Den här mappen är historiken som ska gå att öppna.
